# Pyrtugues — Pacote de documentação

Este pacote contém uma documentação estruturada do Pyrtugues baseada nos arquivos fornecidos do projeto.

## Conteúdo

- `docs/index.md` — índice em Markdown.
- `docs/index.html` — página inicial simples para navegação local.
- arquivos numerados — capítulos da documentação.
- `FONTES-E-NOTAS.md` — origem e limites da documentação.

## Observação de versão

O código Desktop fornecido está em `1.3.0`, mas o README fornecido ainda contém uma referência a `1.2.0`. A documentação registra essa divergência em vez de escondê-la.

## Como usar

Abra `docs/index.md` no GitHub/VS Code, ou abra `docs/index.html` localmente.
